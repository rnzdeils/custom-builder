# Pixtuoid + Herdr V1.7

Aplicador del fork con detección de Herdr, focus, etiquetas completas y último mensaje Claude (si está disponible); incorpora pausa espacial al hover sin congelar el tiempo de la escena.

El preset opcional `Herdr Soft Gray` modifica solamente las constantes de colores ambientales del tema Rust `normal` al momento de compilar. Otros temas, personajes y semántica de estados permanecen intactos. Ver `../README.md` y `apply_soft_gray.py`.

Uso previsto vía GitHub Actions en el repo `custom-builder`. Estado experimental: tests Python superados; Cargo y runtime pendientes.
